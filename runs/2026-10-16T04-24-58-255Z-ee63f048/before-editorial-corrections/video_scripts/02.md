**[VISUAL: Text card — "What to Actually Do"]**

**NARRATION:**
So what's practical here?

All three independent threads point to the same principle: verification has to read state the agent did not author.

**[VISUAL: Simple checklist — each item appears as narrated]**

**NARRATION:**
Check the artifact, not the transcript. If your only evidence that emails went out is the agent's report that it sent them, that's not evidence — it's a claim from a party with a vested interest in the answer. [02-c1]

Alert on zero-effect successes, not just errors. A scheduled agent that reports success having changed nothing is more suspicious than one that threw an exception. [02-c1]

If an agent is discarding solution paths silently, ask it to surface those decisions. Request implementation notes. [02-c3]

If you use a benchmark or evaluation tool, understand who built it and what incentives shaped its construction. [02-c4]
