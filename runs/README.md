# Execution evidence archive

These directories retain actual execution-time configuration, prompts, model responses, editorial decisions, review previews, approvals, errors and recovery receipts. Their historical status labels describe their creation time, not the current publication state. They are preserved for reproducibility and should not be rewritten to imply successful publication at an earlier time.
